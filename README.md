# Slack RAG Chatbot (Gemini + FAISS)

A Slack bot that answers questions about a PDF (the included `zepto.pdf`) using retrieval-augmented generation with Google Gemini.

## What it does
A Flask server receives Slack message events, retrieves the top-6 relevant chunks from a FAISS index built from the PDF, and replies in the same channel with a short, friendly answer generated by Gemini.

## Features
- Slack Events API listener (`/slack/events`) via `slackeventsapi`
- PDF loading (PyMuPDF), chunking (1000/200), Gemini `embedding-001` embeddings, FAISS index saved to `vector_store/`
- `RetrievalQA` ("stuff") chain with custom concise prompt, `gemini-2.0-flash`
- Ignores bot messages; posts a startup message to `#first_chatbot`

## Tech stack
Python, Flask, slackclient / slackeventsapi, LangChain, FAISS, Google Generative AI (Gemini), PyMuPDF, python-dotenv.

## Setup
No requirements file is included; install what `app.py` imports:
```bash
pip install flask slackeventsapi slackclient langchain langchain-community langchain-google-genai langchain-text-splitters faiss-cpu pymupdf python-dotenv
```
Create `.env` with these variable names: `SLACK_TOKEN`, `SIGNING_SECRET`, `GEMINI_API_KEY`.
```bash
python app.py        # Flask on port 5000
```
Expose port 5000 (e.g. with a tunnel), set the Slack app's Event Subscription URL to `<public-url>/slack/events`, and invite the bot to the channel.

## Limitations / future work
- Single hardcoded document and channel name; index rebuilt on each start.
- `allow_dangerous_deserialization=True` when loading the index.
- No requirements.txt, tests or Slack retry/dedup handling.
- Secrets file is committed (see VERDICT).
